Samples

Prepare

Creates the measurement copy (mono, 48 kHz, DC removed, 60 Hz high-pass — the only audio values are read from) and the guide copy (noise-reduced, used only to find events). Voice separation is optional and its bias is measured.

Listen

Separation bias (remix test)

Mixes clean held vowels with real accompaniment, separates the mix, and measures how far each feature moves. The shift is printed beside every value measured from a vocal stem.

Tonic

SonicDiff proposes the tonic (Sa from the drone and melody; key note for Western music). Listen against the reference tone, adjust, and confirm. Pitch is then measured in cents relative to it.

For 78 rpm and tape transfers with a steady drone.

Segment & annotate

Mark phrases (10–30 s, pitch, vibrato, timbre, envelope), held vowels (≥ 1 s, voice quality) and rhythm spans. Label each as free-rhythm or metred and assign the singer. Drag on the waveform to create a segment.

Segment

Drag across the waveform, or select a segment in the list.

Review queue: vibrato or ornament?

Oscillations near the boundary between vibrato (regular, 4.5–7.5 Hz) and ornament (gamak, andolan) wait here for your decision.

Rhythm

Beats are proposed from the accompaniment, but only the marks you confirm are used. Tap the start of each tala or bar cycle while the recording plays.

Analyse

Measures every included segment with the locked constants. Each run stores the constants, software versions and file hashes for reproducibility.

About

VU3INI SonicDiff {{VERSION}} — cross-tradition vocal acoustic comparison for PhD research. By Sasanka Boruah -VU3INI.

Built on Praat (via Parselmouth, GPL), librosa, NumPy, SciPy, statsmodels, pandas, matplotlib, FastAPI, wavesurfer.js and Plotly. Licence texts are in the LICENSES folder. Results describe stylistic difference, not quality.
